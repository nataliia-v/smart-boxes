# Smart Box v2 — робочий чекліст

Без міграції тестових даних. Фото необов’язкове; нова коробка VIEW;
EDIT дозволяє додавати, редагувати та прибирати речі. Коробкою керує лише власник.

## Реалізація
- [x] Next.js + TypeScript strict + Tailwind, видалення старого Apps Script deploy
- [x] PostgreSQL / Prisma, міграції, код Google Auth.js та серверних сесій
- [x] Коробки власника, речі, номери, пошук, пагінація, захист від конфліктів
- [x] QR: показ / PNG / друк, VIEW / EDIT / PRIVATE, ротація токена
- [x] Гостьові операції, транзакційна історія, soft delete, відновлення власником
- [x] Код приватних фото Drive, автоматична папка, шифрування та refresh токенів
- [x] Ліміти запитів / файлів, перевірка фото, обробка незавершених завантажень
- [x] Український адаптивний UI, manifest та іконки
- [x] CI, тести доступу, інтеграційні тести БД, збірка та браузерні перевірки
- [x] Інструкція запуску та налаштування середовищ

Перевірено локально: TypeScript, production build без credentials, 7 unit tests,
3 інтеграційні сценарії з реальною тимчасовою PostgreSQL (Google HTTP підмінений),
початкова SQL-міграція та відсутність schema drift. У браузері: створення коробки,
речі без фото, редагування, стиснення/додавання фото, видалення/відновлення,
історія, налаштування, генерація QR та mobile viewport 390 px.
Живі Google OAuth/Drive та Vercel ще НЕ перевірені.

## Правки після тестування на телефоні
- [x] Картка відкриває редагування цілком, включно з фото; кошик у верхньому правому кутку
- [x] Фото заповнює ширину області картки, опис обмежено двома рядками з багатокрапкою
- [x] QR біля назви коробки, без окремої кнопки оновлення та без напису «Лише перегляд» у власника
- [x] Одна клікабельна область фото з native file picker без примусового capture
- [x] Loader під час декодування та завантаження фото у формі
- [x] Остаточне видалення з «Прибрані», server-side owner check і Drive DELETE
- [x] Видалення попереднього фото після збереження заміни; durable retry при помилці Drive
- [x] Інтеграційні тести: гостю заборонено purge, active/stale item не видаляється, історія лишається, номер не повторюється, cleanup retry
- [x] Браузер 390px: картка/кошик не конфліктують, QR у заголовку, 2 рядки, native picker, loader на повільному фото
- [ ] Повторна перевірка native меню Safari та фактичного видалення тестового фото у Drive власницею
